# Reading Tracker Bot

Telegram-бот для ведения трекинга чтения книг, учета прочитанных страниц и получения персональных рекомендаций.

## Основные возможности

- `/start` — Запуск бота и приветственное меню

- `/track` — Фиксация прочитанных страниц и текущего прогресса

- `/recommend` — Получение подборок и рекомендаций книг

- `/stats` — Просмотр личной статистики чтения

- `/help` — Справка по командам

## Стек технологий

- Python 3.10+

- `python-telegram-bot` (v20+)
